
**This project is a face tracking pong-style game where the user moves their face up and down to control their racket. We used pygame to make the UI and controls for the game, and then we used opencv for the face tracking. The bot you play against has a set moving speed and constantly checks and follows the y value of the ball. The ball starts in the middle at a random angle and rebounds off of the rackets. You play to nine points, and then it has an ending screen based on who reached nine first.
